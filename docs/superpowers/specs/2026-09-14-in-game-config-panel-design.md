# Gun-Tracker 游戏内透明设置面板设计

日期：2026-09-14

## 目标

为 Forge 1.20.1 的 Gun-Tracker 增加一套完整的游戏内中文设置面板。默认使用左 Alt 打开/关闭设置面板；设置面板负责统一管理总开关、自瞄方式、目标筛选、弹道参数、HUD 以及多个“自瞄触发快捷键”。

本次设计保持现有的严格单人模式限制：只有本地集成服务器且玩家数不超过 1 时允许自瞄逻辑生效。多人服务器与多人 LAN 场景不改变现有安全边界。

## 核心架构

采用“统一自瞄配置 + 多个触发入口”的结构。

- 所有快捷键槽位只负责触发同一套自瞄系统。
- 快捷键槽位之间不保存独立的瞄准参数，避免状态冲突。
- 自瞄具体行为（持续追踪、平滑、瞬间甩枪、松开回正、预测、弹道补偿等）统一由自瞄设置控制。
- 总开关位于最上层：关闭后所有触发快捷键都无效，但仍允许打开设置面板修改参数。

## 设置面板

### 打开方式

- 默认：左 Alt 打开/关闭设置面板。
- Alt 不再直接切换持续自瞄。
- 设置面板打开时不执行自瞄触发，避免绑定按键时误触发。
- 面板关闭后恢复正常游戏输入。

### 视觉

- 使用半透明深色背景，不完全遮挡游戏画面。
- 面板本体使用透明/半透明分区，文字保持高对比度。
- 所有标题、按钮、提示、状态、模式名称均提供简体中文。
- 不依赖额外 UI 库，使用 Minecraft/Forge 原生 Screen 和控件体系，减少兼容性风险。

### 页面分区

设置界面按标签页或左侧导航划分为：

1. 总体
2. 自瞄
3. 目标
4. 弹道
5. 快捷键
6. HUD

在较小分辨率下需要支持滚动，而不是挤压控件。

## 总体设置

### 总开关

- 名称：`自瞄总开关`
- 状态：`开启 / 关闭`
- 默认：开启
- 关闭时：不管任何快捷键是否按下，都不会执行锁定、追踪、甩枪或弹道跟踪。

### 自瞄方式

提供统一的行为模式选项，例如：

- `平滑追踪`：按照追踪速度逐步转向目标。
- `瞬间锁定`：触发时直接转向解算后的目标位置。
- `甩枪并回正`：触发时快速吸附目标，松开触发键后按配置速度回到原始视角。

这些属于“自瞄配置”，不是快捷键动作。任意快捷键槽位触发时都使用当前选择的自瞄方式。

## 快捷键系统

### 槽位数量

初始提供 4 个用户快捷键槽位：

- 快捷键 1
- 快捷键 2
- 快捷键 3
- 快捷键 4

以后可扩展槽位数量，但本次不做无限动态列表。

### 每个槽位的 UI

每行结构：

`快捷键 N：[当前绑定 / 请设置快捷键]　触发模式：[模式]`

### 绑定输入

- 点击快捷键按钮后进入“等待输入”状态。
- 下一次键盘键按下即可绑定。
- 下一次鼠标按键按下也可绑定，包括鼠标左右键、中键、侧键等。
- 绑定状态下按 Backspace：清除此槽位，显示 `请设置快捷键`。
- Escape：取消本次重新绑定，不修改原值。
- 同一个物理按键允许被多个槽位绑定，但 UI 可提示“与快捷键 N 重复”；运行时按一次只应计算为一次自瞄触发，避免重复切换。

### 每个槽位的触发模式

每个快捷键槽位独立选择触发方式，但触发的仍是同一套自瞄行为：

- `按住生效`：按住期间启用，松开后停止；如果自瞄方式开启回正，则松开时执行回正。
- `单击切换`：按一次进入激活，再按一次关闭。
- `长按生效`：按住达到长按阈值后才启用，松开结束；用于减少误触。

长按阈值作为一个全局数值配置项，默认约 200 ms，可调整。

### 多快捷键同时输入

- 对“按住生效/长按生效”采用逻辑 OR：只要任意符合条件的快捷键仍在激活，自瞄保持开启。
- “单击切换”维护一个统一的切换状态，而不是每个槽位各自维护自瞄开关。
- 总开关关闭时，所有触发状态强制视为无效。

## 自瞄参数

现有参数继续保留并在新面板中完整暴露，包括：

- 追踪速度
- 甩枪速度
- 松开回正速度
- 平滑子步数
- FOV
- 目标最大距离
- 仅可见目标
- 目标粘滞/切换迟滞
- 瞄准点：头部、胸口、中心、自定义高度
- 移动目标提前量
- 弹速
- 最大预测时间
- 重力补偿
- 弹丸重力
- TACZ 自动读取弹道
- TACZ 实弹校准
- 速度/加速度平滑
- 目标最大速度/最大加速度过滤
- 玩家自身速度继承
- 锁定后重扫间隔

### 距离

距离是核心参数，UI 中单独明确显示：

- 名称：`最大触发距离（方块）`
- 说明：Minecraft 中通常可近似理解为“1 方块 ≈ 1 米”，但配置与计算均使用方块单位。
- 允许范围：4 ～ 300 方块
- 默认值保持现有 96 方块，避免升级后突然扩大锁定范围。
- 滑条旁同时显示准确数字，允许精确调整。

目标搜索、HUD 距离显示和实际触发判定使用同一个配置值，避免 UI 显示与逻辑不一致。

### 数值上限原则

用户希望数值上限尽量大，因此会在不破坏稳定性的前提下扩大现有限制：

- 最大距离：300 方块
- FOV：最大 180°
- 平滑子步数：扩大到高于现有 8 的合理范围
- 预测时间：扩大到高于现有 40 tick 的合理范围
- 手动弹速、目标速度、目标加速度等扩大范围
- 不使用无限值、NaN 或极端到足以导致数值溢出/明显卡顿的上限

最终具体上限将在实现时集中定义，UI 与 ForgeConfigSpec 共用同一组常量，避免两套范围不一致。

## 目标模式

继续支持并完整汉化现有目标分类：

- 仅敌对生物
- 全部生物（不含玩家）
- 全部活体实体

并继续支持：

- 仅可见目标
- 粘滞目标
- 切换迟滞
- 瞄准点选择

本次不新增针对多人玩家的特殊目标模式；严格单人限制保持不变。

## HUD

提供：

- HUD 总显示开关
- FOV 圆环开关
- 弹道信息 HUD 开关
- 当前目标名称与距离（方块）
- 当前自瞄总开关状态
- 当前激活状态
- 当前自瞄方式
- 当前弹道来源（TACZ 实弹校准 / TACZ 数据 / 手动参数）

所有 HUD 文字使用简体中文翻译键。

## 配置持久化

- 继续使用现有 Forge CLIENT config 保存数值、布尔和枚举项。
- 新增总开关、自瞄方式、长按阈值等配置项。
- 快捷键本身优先沿用 Minecraft KeyMapping 持久化机制；需要支持鼠标按键和多槽位。
- 每个槽位的触发模式保存在 CLIENT config。
- 旧配置文件升级时，缺失的新字段使用默认值，不要求用户删除旧配置。

## 代码边界

预计按职责拆分：

- `Config.java`：配置定义、范围常量、枚举，不再承担完整大型 UI 实现。
- 新 `GunTrackerConfigScreen.java`：透明设置面板、分页、滑条、切换按钮、快捷键捕获 UI。
- `Keybindings.java`：Alt 面板快捷键 + 4 个自瞄触发 KeyMapping。
- 新 `AimActivationController.java`：统一处理多个快捷键槽位的按住/切换/长按状态，向 AimHandler 暴露统一“当前是否激活”。
- `AimHandler.java`：只负责根据激活状态和当前自瞄方式执行跟踪/甩枪/回正，不直接解析多个输入槽位。
- `zh_cn.json` / `en_us.json`：完整界面与模式文本。中文是默认重点，英文保持基本对应，避免缺失翻译键。

这种拆分避免继续把所有 UI、配置、输入状态都堆进已经很大的 `Config.java`。

## 输入与状态规则

- 打开设置面板时，清空临时按住/长按状态，防止退出面板后自瞄意外保持。
- 修改快捷键时不触发自瞄。
- 总开关从开变关时，立即清除当前目标、回正/甩枪临时状态和切换激活状态。
- 进入非严格单人环境时，保持现有行为：自瞄强制失效并清理状态。
- 返回严格单人环境后不会自动重新激活，需要用户重新按触发键。

## 测试与验证

至少验证：

1. Alt 能稳定打开/关闭设置面板，不再切换自瞄。
2. 4 个槽位均可绑定键盘键。
3. 4 个槽位均可绑定鼠标键。
4. Backspace 可清除任一槽位。
5. Escape 可取消绑定。
6. 按住模式按下/松开行为正确。
7. 单击切换模式不会因重复绑定而双重切换。
8. 长按在阈值前不触发、达到阈值后触发。
9. 总开关关闭时任何快捷键都无法激活。
10. 最大距离可以设到 300，并且实际搜索/显示使用同一值。
11. 三种自瞄行为模式按配置工作。
12. 松开回正仅在相关自瞄方式/配置启用时执行。
13. 设置保存后重新进入世界/重启客户端仍保留。
14. 严格单人限制没有被破坏。
15. `gradle clean build --stacktrace --no-daemon` 在 GitHub Actions 上成功。
16. Actions 成功上传 `build/libs/*.jar` Artifact。

## 非目标

本次不做：

- 多人服务器可用化
- 自动识别最佳按键布局
- 无限数量快捷键槽位
- 每个快捷键保存不同的自瞄参数预设
- 外部 GUI 库或主题系统
- 宏序列、连点器等与自瞄触发无关的输入功能
