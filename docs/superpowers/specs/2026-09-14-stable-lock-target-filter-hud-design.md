# Gun Tracker 稳定锁定、目标筛选与 HUD 重构设计

日期：2026-09-14

## 1. 背景与目标

当前版本已经具备透明设置面板、4 个触发快捷键、三种自瞄行为、TACZ 弹道预测、目标筛选和 HUD，但实际体验存在以下问题：

1. 三种自瞄模式差异不明显。当前默认参数下，平滑追踪速度接近 1.0，瞬间锁定直接使用 1.0，甩枪回正默认甩枪速度也为 1.0，因此视觉上非常接近。
2. 非瞬间模式的“平滑”主要依赖单 tick 内重复旋转，并不是真正跨 tick 的阻尼追踪；目标预测点轻微变化时，视角会出现一卡一卡、抽搐或微振。
3. 锁定状态仍会定期扫描全部候选，并可能被一瞬间评分更优的新目标抢走，导致多人或多怪场景频繁换人。
4. 目标类型是单选枚举，无法让用户自由组合“玩家 / 敌对怪物 / 其他生物”。
5. 盔甲架、NPC、训练假人、伪玩家缺少明确过滤策略。
6. HUD 无法作为可靠的常驻总开关状态指示器，位置也不能自由移动。

本次目标是在不推翻现有 TACZ 弹道解算和 4 槽位触发框架的前提下，重构：稳定锁定、视角输出、目标筛选、防假人、常驻 HUD 和总开关键。

## 2. 总体架构

保留：

- `TaczBallistics` 与 `BallisticsMath`
- 现有弹速、摩擦、重力、提前量和动态校准机制
- 4 个自瞄触发槽位及其按住 / 切换 / 长按模式
- 最大 300 方块搜索距离
- 透明设置面板和中英文语言资源框架

重构或扩展：

- `TargetSelector`：改为“当前锁定 + 替代候选 + 粘滞确认”的状态机。
- `AimHandler`：改为跨 tick 的模式化视角控制。
- `TargetMotionTracker` / 角度输出：增加低通与最大角速度限制。
- `Config`：增加组合目标筛选、防假人、粘滞参数、模式专属参数、HUD 坐标与显示项。
- `GunTrackerConfigScreen`：重新组织自瞄、目标、快捷键和 HUD 页。
- `AimHud`：改为常驻、可移动、可配置内容的状态组件。
- `Keybindings`：增加独立的“切换自瞄总开关”快捷键。

不恢复旧版本的严格单人限制；本次以当前用户上传的基准包行为为准。

## 3. 稳定锁定状态机

### 3.1 状态

系统维护：

- 当前锁定目标 `currentTarget`
- 当前替代候选 `candidateTarget`
- 候选已连续保持优势的 tick 数
- 当前目标连续不可见 tick 数
- 上次候选扫描 tick

### 3.2 无目标时获取

没有当前目标时：

1. 目标类别过滤。
2. 防假人过滤。
3. 存活 / 移除 / 距离过滤。
4. 搜索 FOV 过滤。
5. 若启用“仅可见目标”，执行可见性过滤。
6. 计算基础评分并选择最佳目标。

基础评分沿用“准星角度优先、距离次要”的思路，但**不再通过 currentTarget 的固定减分来实现粘滞**。粘滞由独立状态机处理，避免双重加权。

### 3.3 粘滞强度 0～100

新增 `粘滞强度`，范围 0～100，默认 85。

将强度映射为候选必须超过当前目标的最低评分优势：

`switchMargin = 2.0 + 0.48 * stickiness`

因此：

- 0 → 2.0 分
- 50 → 26.0 分
- 85 → 42.8 分
- 100 → 50.0 分

现有基础评分中角度约占 `角度 × 10`，因此默认 85 相当于新目标通常需要至少约 4° 以上的明显角度优势，才有资格进入切换确认。

### 3.4 切换确认

新增 `切换确认时间`，范围 0～60 tick，默认 12 tick。

新增 `候选扫描间隔`，范围 1～10 tick，默认 3 tick。

锁定有效时：

- 每 3 tick 扫描一次潜在替代目标，而不是每 tick 全量扫描。
- 若同一个候选持续满足 `candidateScore + switchMargin < currentScore`，确认时间按实际经过 tick 累加。
- 候选变化、失去优势、离开范围或被过滤，确认计数立即清零。
- 达到 12 tick 后才切换。

粘滞强度 100 也不是绝对禁止切换；持续明显更优的候选仍可在确认完成后替换目标。

### 3.5 当前目标失效

以下情况立即解除当前目标：

- 死亡
- 实体被移除
- 超出最大距离
- 不再属于用户勾选的目标类别
- 被当前防假人规则判为无效
- 超出脱锁 FOV

解除后可在下一次正常扫描中重新获取目标。

### 3.6 不可见容忍

新增 `不可见容忍时间`，范围 0～60 tick，默认 10 tick。

若开启“仅可见目标”：

- 获取新目标时必须立即可见。
- 已锁目标暂时不可见时继续保持锁定，但累加不可见 tick。
- 恢复可见后计数归零。
- 连续不可见超过 10 tick 后解除。

### 3.7 搜索 FOV / 脱锁 FOV

- 搜索 FOV：沿用现有，范围 5～180°，默认 70°。
- 脱锁 FOV：新增，范围 5～180°，默认 110°。

新目标必须位于搜索 FOV 内；已锁目标只要仍位于脱锁 FOV 内即可保持。

保存时若脱锁 FOV 小于搜索 FOV，自动将脱锁 FOV 提升到搜索 FOV。

## 4. 三种自瞄模式

三种模式的默认值必须直接产生明显差异。

### 4.1 共用角度稳定层

所有模式都先执行：

1. 现有目标运动 / TACZ 弹道预测得到预测点。
2. 转换为目标 yaw / pitch。
3. 对 wrapped yaw 和 pitch 做跨 tick EMA 稳定。
4. 限制异常单 tick 角度跳变。
5. 再交给模式控制器产生实际视角移动。

新增 `视角稳定度`，范围 0～100，默认 70。

稳定度映射到目标角 EMA 新样本权重：

`alpha = 0.65 - 0.50 * (stability / 100)`

因此默认 70 → alpha 0.30。稳定度越高，预测点短时抖动对视角影响越小。

切换到新目标时重置该目标角滤波器，避免旧目标残留拖拽。

### 4.2 平滑追踪（SMOOTH_TRACK）

定位：自然、连续、稳定追踪。

默认：

- 跟随增益：0.28
- 最大转向：10° / tick
- 使用共用稳定度 70

每 tick：

- `delta = wrapped(target - current)`
- 实际移动量为 `delta × followGain`
- 再分别钳制到最大转向角

不再使用“同一个 tick 内循环多个 substep”作为主要平滑方式。旧 `AIM_SUBSTEPS` 只保留兼容，不进入新版主要视角控制。

用户可调：跟随增益 0.05～1.0、最大转向 1～90°/tick、稳定度 0～100。

### 4.3 瞬间锁定（SNAP）

定位：首次获取立即甩准，之后稳定高速跟随。

默认：

- 首次获取：直接对准一次
- 后续跟随增益：0.55
- 后续最大转向：18° / tick
- 稳定度：共用 70

“直接对准”只发生在：

- 从无目标首次获取目标
- 粘滞状态机正式切换到另一个目标

后续 tick 不再无限重复瞬间写入预测角度，因此 SNAP 不再成为持续抖动源。

### 4.4 甩枪并回正（FLICK_RETURN）

定位：快速甩向目标，保持一段稳定追踪，释放后回到原视角。

默认：

- 首次快速甩枪增益：0.75
- 首次快速甩枪最大转向：35° / tick
- 进入目标附近后的持续跟随增益：0.40
- 持续跟随最大转向：15° / tick
- 回正增益：0.35
- 回正最大转向：30° / tick

触发开始时保存原始 yaw / pitch。

首次获取时不是 SNAP 那样一步瞬间到位，而是用更大的每 tick 角速度快速甩过去，因此视觉上与 SNAP 明显不同。

当 yaw/pitch 总误差进入 1.0° 内后转入持续跟随参数。

释放后停止选目标，按回正参数逐 tick 返回原始视角；误差小于 0.25° 时结束回正并精确落在原始角度。

## 5. 组合式目标筛选

新 UI 使用三个独立布尔类别：

- `锁定玩家`：默认开启
- `锁定敌对怪物`：默认开启
- `锁定其他生物`：默认关闭

定义：

- 玩家：`Player`
- 敌对怪物：`Monster`
- 其他生物：其余 `LivingEntity`

设置页提供“全体可锁定实体”快捷按钮，用于一次性全选 / 全不选三个类别。

三个类别全关时，不获取任何新目标，但总开关仍可保持开启。

不锁定非活体对象，例如掉落物、箭、子弹、经验球、方块实体。

## 6. 防假人 / 防盔甲架

新增 `防假人模式`：

- 关闭
- 标准过滤
- 严格过滤

默认：标准过滤。

### 6.1 盔甲架

`ArmorStand` 永远过滤，与防假人模式无关。

### 6.2 标准过滤

普通非 Player 生物不做额外假人检测。

Player 必须能通过客户端连接按 UUID 找到 `PlayerInfo`；无法找到则视为 NPC / 假人并过滤。

### 6.3 严格过滤

严格过滤包含标准过滤，并额外检查 Player 的资料一致性。

严格模式只有在出现明确硬异常，或至少两个软异常同时成立时才额外过滤，避免单一启发式误杀真人。

硬异常：

- 空 / nil UUID
- 同一世界中出现互相冲突的重复 Player UUID
- 实体 UUID 与对应 `PlayerInfo` UUID 不一致

软异常示例：

- GameProfile 名称为空或超出正常玩家名长度
- 实体 GameProfile 名称与 PlayerInfo profile 名称不一致
- 必需 profile 信息缺失

不使用“站着不动、移动方式异常、AFK、视角不动”等行为作为假人判据。

严格模式是启发式过滤，不承诺识别所有模组 NPC；中文 UI 明确提示其误过滤风险高于标准模式。

## 7. 总开关快捷键

新增 KeyMapping：`切换自瞄总开关`。

要求：

- 默认未绑定。
- 支持键盘和鼠标。
- 设置面板内直接捕获。
- Backspace 清除，Esc 取消捕获。
- 每次按下切换 `MASTER_ENABLED`。
- 关闭时立即清除当前锁定、候选确认、视角滤波和回正状态。
- 再开启不会自动控制视角，仍需通过 4 个触发槽位激活自瞄。

4 个现有触发槽位继续只负责自瞄激活。

## 8. 常驻可拖动 HUD

### 8.1 状态框

默认始终显示，即使总开关关闭也显示。

默认内容：

```text
自瞄：开启
模式：平滑追踪
锁定：Steve 23.6方块
```

总开关关闭时至少显示：

```text
自瞄：关闭
```

### 8.2 独立显示项

HUD 页提供：

- 显示状态框
- 显示总开关状态
- 显示当前模式
- 显示目标名称
- 显示目标距离
- 显示 FOV 圈
- 显示弹道信息

默认：状态框、总开关状态、模式、目标名称、目标距离开启；FOV 圈与弹道信息沿用用户现有配置或旧默认。

### 8.3 可拖动位置

HUD 页提供：

- `调整 HUD 位置`
- `恢复默认位置`

进入定位界面后显示 HUD 预览，鼠标左键拖动，松开保存；Esc 取消并恢复进入前位置。

保存归一化坐标 `hud_x` / `hud_y`，范围 0.0～1.0，并在渲染时根据 GUI 尺寸换算像素位置。拖动时要将状态框边界钳制在屏幕内。

默认锚点：水平 0.5，垂直约 0.58，即准星下方。

## 9. 设置面板

### 9.1 总体页

- 自瞄总开关
- 当前自瞄模式
- 长按阈值
- 总开关快捷键绑定

### 9.2 自瞄页

只显示当前模式实际生效的参数，避免无效开关。

通用：

- 视角稳定度

平滑追踪：

- 跟随增益
- 最大转向速度

瞬间锁定：

- 后续跟随增益
- 后续最大转向速度

甩枪并回正：

- 首次甩枪增益
- 首次最大转向速度
- 持续跟随增益
- 持续最大转向速度
- 回正增益
- 回正最大转向速度

### 9.3 目标页

按以下顺序：

1. 最大距离（4～300 方块）
2. 搜索 FOV
3. 脱锁 FOV
4. 仅锁可见目标
5. 锁定玩家
6. 锁定敌对怪物
7. 锁定其他生物
8. 全体可锁定实体快捷操作
9. 防假人模式
10. 粘滞强度 0～100
11. 切换确认时间
12. 候选扫描间隔
13. 不可见容忍时间
14. 瞄准位置
15. 自定义瞄准高度

旧“粘滞目标”布尔入口从新 UI 移除，新状态机始终启用；粘滞强度 0 表示最低粘滞。

### 9.4 HUD 页

- 所有 HUD 独立显示开关
- 调整 HUD 位置
- 恢复默认位置

## 11. 配置兼容

旧配置继续允许存在，避免因为删除 Forge config 键导致升级风险。

迁移策略：

- 旧 `TARGET_MODE` 仅作为迁移来源：
  - HOSTILE_ONLY → 玩家 false / 敌对 true / 其他 false
  - MOBS_ONLY → 玩家 false / 敌对 true / 其他 true
  - ALL_LIVING → 三类 true
- 旧 `STICKY_TARGET` 和 `SWITCH_HYSTERESIS` 不再作为新版运行时的主要锁定逻辑；如果新粘滞配置不存在，首次迁移时用旧值生成合理初始值，之后以新值为准。
- 旧 `AIM_SUBSTEPS` 保留配置兼容，但新版视角控制不依赖它。
- 无 HUD 坐标时使用 0.5 / 0.58。

迁移只能在新配置尚未由用户显式保存时执行，不能每次启动覆盖用户的新设置。

## 12. 性能约束

300 方块范围可能包含大量实体，因此：

- 无目标时按扫描间隔搜索。
- 有目标时每 tick只做当前目标有效性与视角更新。
- 替代候选默认每 3 tick 扫描一次。
- 类型、存活、距离、FOV 等便宜过滤先执行。
- 可见性射线和 PlayerInfo / profile 检查只对通过前置过滤的候选执行。
- 不要求每 tick 求全世界绝对最优目标。

## 13. 测试策略

### 13.1 纯逻辑测试

尽量抽离并测试：

- 0～100 粘滞值到 `switchMargin` 的映射
- 同一候选连续确认与候选变化清零
- 失效目标立即解锁
- 搜索 FOV / 脱锁 FOV 双阈值
- 不可见容忍计数
- 三种模式首次获取 / 持续跟随 / 释放状态转换
- wrapped yaw 平滑与最大角速度限制
- HUD 归一化坐标及屏幕边界钳制
- 旧 `TargetMode` 迁移映射

### 13.2 行为测试

至少覆盖：

1. 两个目标交叉不会快速来回切换。
2. 新目标短暂更优但不足 12 tick 不切换。
3. 同一个新目标持续明显更优达到确认时间后会切换。
4. 当前目标死亡 / 移除 / 超距立即解锁。
5. 当前目标短暂遮挡 10 tick 内保持锁定。
6. 盔甲架永远无效。
7. 标准防假人过滤没有正常 PlayerInfo 的 Player。
8. 严格模式不会仅因 AFK / 静止过滤真人。
9. 玩家 / 敌对怪物 / 其他生物可以任意组合。
10. SNAP 只在首次获取或正式换锁时瞬间甩准。
11. FLICK_RETURN 释放后逐 tick 回原视角。
12. 总开关键关闭立即停止视角控制。
13. HUD 坐标拖动、保存、取消和恢复默认均正确。

### 13.3 构建验证

最终必须运行完整：

```text
gradle clean build --stacktrace --no-daemon
```

并通过 GitHub Actions Forge 1.20.1 云编译后才交付 JAR。

## 14. 完成标准

以下条件必须同时满足：

- 默认锁定明显减少频繁换人。
- 粘滞强度 0～100 对换锁行为有可测试、可感知影响。
- 三种模式默认体验明显不同。
- 平滑追踪不再依赖单 tick 子步伪平滑，抽搐明显降低。
- 用户可组合玩家 / 敌对怪物 / 其他生物。
- 盔甲架永远不会被锁定。
- 防假人支持关闭 / 标准 / 严格三档。
- 总开关键支持键盘 / 鼠标，Backspace 可清除。
- 常驻 HUD 明确显示总开关状态并可拖动。
- 新增 UI 全部有简体中文与英文 fallback。
